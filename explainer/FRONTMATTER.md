# 阅读路线与术语索引

本书不是论文摘要。第1章补足本题所需背景，第2—8章沿英文正文展开证明，最后解释两个保留的附录。可以从头读，也可以按英文编号跳转。无需回答问题或等待对话；不理解某一步时，将英文编号、中文节号或HTML链接带到另一个同项目对话，并让它先读`READING_START.md`。

整条证明只有一条主线：**用平方与交换关系建立计数接口 → 用三个字符和及其对偶求界 → 从下端等号确定极化结构 → 保留全部线性细化 → 以同一个目标换基归一 → 转回群同构。** 数值界的端点构造独立完成，不调用后面的分类定理来证明自身可达。
